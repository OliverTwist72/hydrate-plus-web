# HYDRATE PLUS – GitHub Pages

Separate statische Website, abgeleitet von den bereitgestellten PROTEIN-PLUS-Quelldateien. Vier Seiten in Deutsch und Englisch sowie ein gemeinsames Stylesheet.

## Veröffentlichung
1. Auf GitHub ein **neues**, öffentliches Repository `hydrate-plus-web` anlegen.
2. Den **Inhalt** dieses Ordners in das Repository-Root hochladen.
3. Unter **Settings → Pages → Build and deployment** die Option **Deploy from a branch**, Branch `main`, Ordner `/ (root)` wählen.
4. Nach der Veröffentlichung die Seiten im Browser kontrollieren.

## Vor der Veröffentlichung prüfen
- Original-Farbcodes der HYDRATE-PLUS-App: Die CSS-Farben sind eine gestalterische Annäherung, keine aus Xcode verifizierten Markenwerte.
- Mit Astra die tatsächliche Speicherung, Benachrichtigungen, StoreKit, Trackingfreiheit und Testphase gegen den finalen App-Build abgleichen; Datenschutzerklärung bei Bedarf korrigieren.
- Anbieterangaben und Preis mit dem finalen App-Store-Connect-Eintrag abgleichen.
- Deutsch/Englisch-Verlinkung und Darstellung auf iPhone prüfen.
- PROTEIN PLUS bleibt vollständig unberührt.
